## 二、仍需确认的项目

| 编号 / 优先级 | 项目                                   | 当前结论与影响                                                                                                                    | 最直接的查证方法                                                            |
| -------- | ------------------------------------ | -------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------- |
| T01 / 高  | V851SE 88 脚 `VDD_SYS6/VDD_EPHY` 电源归属 | 现有引脚名称/参考资料存在歧义；**不能标 NC，也不能凭相邻引脚猜电压**。这影响主控与集成 EPHY 供电。                                                                   | 向全志或模组/芯片供应方索取与实际封装、硅版本匹配的引脚表及参考原理图，核实该脚电压和退耦。                      |
| T02 / 高  | 摄像头 FPC 23、24 脚                      | 现按 `23→1V5`、`24→CAM_2V8` 绘制；供应商表格末两行都印作“24”，23 的功能是按顺序推断。传感器裸片引脚表**不能代替模组 FPC 引脚定义**。                                      | 请实际 MCM03M180M7 模组供应商提供修订版 24-pin pinout，逐一确认引脚号、方向和电源。             |
| T03 / 高  | 主控与相机真实上电次序                          | 两份芯片手册给出了先后约束；现有 EN/RC 网络未用实测波形证明满足。尤其 V851SE 的 `VCC_LDOA&PLL→0V9→复位` 与相机 `1V8→1V5→2V8→XSHUTDN`。                           | 完整工程阶段核对 EA3056 EN、PG/复位和相机 XSHUTDN 的逻辑；样机用示波器同时测各轨、时钟和复位。          |
| T04 / 高  | 真实电流、效率和温升                           | [设计说明](设计说明文档.md)的 11.06 W@5 V 是**明示假设的预算样例**。V851SE 资料未给全部工作模式电流；SC035HGS 表 3-2 的工作电流栏为空。模组资料写 85 mA，但未拆分到三路供电，不能直接当最坏功耗。 | 取得芯片/模组典型与峰值电流表；样机测待机、取图、编码上传和 LED 常亮工况；复算 SY8493、EA3056 和 PoE 余量。  |
| T05 / 高  | LED 电阻功率与亮度漂移                        | 按现有 5 V、电阻和典型/较低 Vf 条件，红外每颗限流电阻约 1.08 W，白光每颗约 0.76 W。红外 VF 最小值/热态电流尚无闭合上限，长亮功率必须测。                                         | 最终 BOM 选 R6/R7 ≥2 W、R8/R9 ≥1 W（优先 2 W）且检查高温降额；量测热态电流与电阻温升，必要时换恒流驱动。 |
| T06 / 高  | PoE Type 2 判定与 Type 1 降功耗            | 硬件 `T2P` 状态已计划送主控，但全功能负载不能在仅获 Type 1/13 W 时自动启动。                                                                           | 固件上电先关高功率 LED；读取 Type 2 状态后再放行；测试 Type 1 与 Type 2 两种 PSE。           |
| T07 / 中  | FOV 与镜头座                             | 拟选 MCM03M180M7 是 **M7** 镜头座、默认对角 FOV 60°，需求写四个光学器件各用 **M12**。裸 LED 与光电二极管角度远宽于相机。                                          | 面试稿明确“拟选 M7 模组”；若坚持 M12，换 M12 相机模组/适配座并重核 FPC。确定工作距离后标定三个有效区域的空间重合。 |
| T08 / 中  | 环境光抗扰与光学滤波                           | VBPW34S 对可见光也灵敏；PWM 阈值可调不等于日照下零误触发。                                                                                        | 选择约 950 nm 窄带滤片、遮光筒及环境光基线策略；在日照、室内频闪和不同目标材质下测误触发率。                  |
| T09 / 中  | 时间戳精度与触发延迟                           | 比较器到相机为硬件路径；主控 GPIO 软件中断记时会有调度抖动。要求中的“瞬时拍照”不等于立即得到或传完图像。                                                                   | 选可接触发信号的定时器捕获/GPIO 时间戳方案；样机同时测比较器输出、TRIG、曝光/帧有效及上传完成时间。             |
| T10 / 中  | 外触发模组引脚与控制极性                         | 裸 SC035HGS 资料确认 `TRIG` 上升沿及 `XSHUTDN` 低有效；模组 FPC 的 `CAM_TRIG_OC`、`CAM_PWDN` 是否直达这些引脚仍以模组定义为准。                              | 取得模组原理图/时序表；用示波器检查相机端实际电压沿，并验证触发寄存器配置。                              |
| T11 / 中  | USB 下载/FEL 与正常启动切换                   | 原理图提供 SD NAND、USB 与 UART 调试通道；尚未确认该 V851SE 版本所需的启动脚状态、FEL 入口和量产烧录步骤。                                                       | 对照实际 SDK/启动 ROM 说明，验证 SD NAND 正常启动、强制 USB 下载与恢复流程。                  |
| T12 / 中  | USB 与 PoE 同时连接                       | 本稿按两种供电不同时使用说明。USB 路径里的 0 Ω/二极管不能单独证明所有接入次序下不会回灌；0.5 A 保险丝也不足以支持 LED 全亮工况。                                                 | 若需要现场同时接电脑，重新核对电源 OR-ing、VBUS 回灌、地与隔离及 Type-C 功率协商；做插拔测试。           |
| T13 / 低  | 白光 LED 精确 BOM、光谱及 FOV                | 原理图使用 LH351B 系列 3535 白光 LED，需求中的可采购料号/色温/光束整形尚未最终锁定。                                                                       | 用最终采购料号对应的厂商资料核对 Vf、光通量、色温、封装热阻，并与 M12 光学方案一并定型。                    |
| T14 / 低  | 24 MHz 晶振和相机/EPHY 时钟细节               | 已明确时钟架构，但晶振负载电容、实际相机 MCLK 频率及 EPHY 时钟配置尚无样机波形。                                                                             | 根据 X2 的负载电容和主控引脚电容复算 C5/C6；检查 SDK 时钟树，样机量测 MCLK/网络工作状态。             |
