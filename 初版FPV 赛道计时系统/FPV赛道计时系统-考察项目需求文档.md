## 1. 系统概述

本系统为一套 FPV 赛道计时设备：目标（赛车/穿越机）经过光电门时，系统以红外光照 + 光电探测实现**瞬时触发**，触发全局快门相机**瞬时拍照**，并通过 **POE 单线（100 Mbps 以太网数据 + 供电）**把带时间戳的图像与计时结果上传上位机。

### 1.1 系统关键要求
- 建立「**触发 → 拍照 → 上传**」闭环链路；
- 触发到出图延迟尽量小，且触发检测区与拍摄视场一致（FOV 对齐）；
- 用**比较器**实现**软件可控阈值**的**硬触发**；
- **单线 POE**（供电 + 数据一体）。

## 2. 系统组成与架构

```
[上位机/服务器] ◄── POE 100 Mbps（供电 + 数据 单线）──► [本设备]

本设备：
  POE 前端：RJ45(HY931147C 集成磁隔离变压器+LED) + TPS2378DDAR(PoE+ PD, 25 W)
      ├─ 48V ─► SY8493(48→5V, 3 A) ─► EA3056(4 路 PMIC) ─► V851SE 及系统各供电  [电源轨 TBD]
      └─ MDI ─► V851SE 集成 EPHY (SIP 100 M)
  V851SE 主控
      ├─ MIPI CSI ◄─ SC035HGS (全局快门 0.3MP，支持外触发)
      ├─ SD/SDIO ─► CSNP1GCR01-BOW (1 Gb 贴片 SD NAND，启动介质)
      ├─ GPIO/PWM ─► 比较器阈值(DAC / PWM-RC) + LED 调光
      ├─ 触发输入 ◄─ 比较器输出 ◄─ 比较器(LM393) ◄─ 光电二极管(VBPW34S)
      └─ LED 驱动 ─► 2×3535 白光 + 2×红外灯(JNJ-LOJV0111W140)  [LED 驱动 TBD]
  USB/Type-C 调试口：USB 2.0 (D+/D−, CC, ID, VBUS)，用于烧录/调试，可作开发期本地 5V 供电
光学：白光照明 / 红外照明 / 光电检测 / 拍摄 均装各自 M12 镜头座，
      镜头使「照明、触发、拍摄」有效视场角一致。
```

**触发链路**：
```
VBPW34S(光电二极管) ─► 负载电阻/跨阻 转电压 ─► 比较器(LM393) 一脚
                                               另一脚 ◄─ DAC 或 PWM-RC 滤波(软件可控阈值)
                              比较器输出 ─► 外部触发 ─► SC035HGS 外触发脚(全局曝光)
```

## 3. 功能需求

- **F01** 系统须能检测目标进入光电门检测视场，并产生**触发信号**。
- **F02** 系统须在触发后由全局快门相机完成**一次拍照**。
- **F03** 系统须为每次触发记录**时间戳**，并把「图像 + 时间戳 + 触发序号」经 **POE 100 Mbps 以太网**上传上位机。
- **F04** 系统须支持对比较器阈值进行**软件设置**（灵敏度可调）。
- **F05** 系统须提供红外触发照明与可见补光。
- **F06** 系统须支持触发与拍摄视场（FOV）对齐。

---

## 4. 接口需求

- **IF01 电源/网络**：单线 **POE**，供电 + 100 Mbps 以太网数据，支持 802.3at（25 W）。
- **IF02 摄像头**：**MIPI CSI-2** 接口（SC035HGS，1/2 lane）。
- **IF03 触发**：LM393 比较器输出作为**硬触发**，经 **SC035HGS 外触发脚**触发全局曝光；阈值由软件（DAC / PWM-RC）设定。
- **IF04 调试/烧录**：**USB 2.0 Type-C**（D+/D−、CC、ID、VBUS，带 ESD）。

---

## 5. 电源需求

- **P01** 整机功耗须在 **PoE 802.3at（25 W）** 预算内，并留降额余量；须给出整机功率核算。
- **P02** 电源层级：**48V → 5V → 系统各轨**；须满足各负载电流要求。
- **P03** 电源树各 rail 电压/电流/时序须以 V851SE、SC035HGS 数据手册为准。

---

## 6. 时序需求

- **T01** 系统须满足 **V851SE 与 SC035HGS** 的上电时序要求（各 rail 先后、复位释放时机）。
- **T02** 触发到出图延迟须尽量小；触发检测区与拍摄视场一致。

---

## 7. 启动与烧录需求

- **B01** 系统须从板载 **CSNP1GCR01-BOW**（1 Gb SD NAND，SPI/SD）启动。
- **B02** 系统须支持固件烧录（如 **USB 下载/FEL** 模式），并说明烧录与启动模式切换方式。

---

## 8. 光学需求

- **O01** 白光照明、红外照明、光电检测、拍摄的有效视场角（FOV）须一致；各光电器件安装于各自 M12 镜头座。

---

## 9. 可靠性与环境需求

- **R01** 触发检测须抗环境光（日光）干扰，红外与可见光谱须区分。
- **R02** 工作温度、湿度等环境参数以器件规格书为准（SC035HGS 宽温 -30~85 °C）。
